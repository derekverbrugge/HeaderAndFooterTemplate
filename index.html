What makes this simple?

Plain HTML

Each page is ordinary HTML. There is no framework and no special templating language.

Small JavaScript

JavaScript has one primary job: load reusable pieces of HTML and add only the behavior we need.

Shared CSS

One stylesheet controls the appearance of every page.
