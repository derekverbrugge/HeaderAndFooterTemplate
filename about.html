How this site works

The header and footer are stored separately so they don't have to be copied into every page.

The basic idea

Every page contains an empty element with the ID site-header. 

<div id="site-header"></div>

JavaScript finds that element and loads header.html into it. 

loadPartial("site-header", "header.html");

The footer works exactly the same way. 

loadPartial("site-footer", "footer.html");
